# React 19 TodoList CRUD Application

Aplikasi TodoList interaktif berbasis React 19, Vite, dan React-Bootstrap.
Dibuat untuk memenuhi Tugas Praktikum 6 Mata Kuliah Pemrograman Full Stack.

## Fitur Utama
- **CRUD Operations**: Tambah, Tampil, Edit, dan Hapus tugas.
- **Visual Badges**: Lencana warna indikator Priority (High/Medium/Low) & Status (To Do/In Progress/Done).
- **Timestamp**: Waktu pembuatan tugas secara otomatis.
- **Real-time Filter**: Pencarian tugas berdasarkan nama kegiatan.
